# 向量检索入门

## 距离度量

向量检索要先有一个距离函数来衡量"两个向量有多像"。常见的有余弦相似度、内积与欧氏距离三种。

| 度量 | 取值范围 | 特点 |
| --- | --- | --- |
| 余弦相似度 | -1 到 1 | 只看方向，对向量长度不敏感 |
| 内积 | 无界 | 计算最快，但要求向量已归一化 |
| 欧氏距离 | 0 到正无穷 | 越小越像，对量纲敏感 |

## 近似最近邻

精确找最近邻要遍历全部向量，数据量大时不可接受。HNSW 用分层图把搜索复杂度降到近似对数级：上层稀疏、用于快速跳转，底层稠密、用于精确定位。

## 混合检索与 RRF

纯向量检索对专有名词、型号、编号不敏感，因为这些词的语义信息很弱；关键词检索恰好擅长这一类。两者用 RRF 融合时按名次取倒数相加，而不是把分数直接相加，因此不需要对齐量纲。

# 检索评测指标

## recall@k

recall@k 衡量"前 k 个结果里是否包含标准答案"，只看有没有命中、不看名次。k 一般取 1、5、10 三个点。

## MRR

MRR 取命中名次的倒数再求平均，所以把答案从第 5 名提到第 1 名，收益远大于从第 20 名提到第 10 名。它比 recall@k 更敏感。

## NDCG

NDCG 允许给多个相关结果标注不同等级，再按位置衰减求和。适合"一个问题的答案可能分布在多处"的场景。

| 指标 | 是否看名次 | 是否支持多档相关 |
| --- | --- | --- |
| recall@k | 否 | 否 |
| MRR | 是 | 否 |
| NDCG | 是 | 是 |

## 黄金集的坑

语料太小会让 recall@5 直接饱和在 1.0，任何改动都测不出来。集子里必须有**看起来都相关**的干扰文档，并且要注意"一条样本就是 1/N"——N 小于一百时，任何差异都可能是噪声。

# 线程池参数速查

## 核心参数

线程池的行为由几个参数共同决定，理解它们的配合方式是排查问题的前提。

| 参数 | 含义 | 常见取值 |
| --- | --- | --- |
| corePoolSize | 核心线程数 | CPU 核数 |
| maximumPoolSize | 最大线程数 | 2 倍 CPU 核数 |
| keepAliveTime | 空闲回收时间 | 60 秒 |
| workQueue | 任务队列 | 优先用有界队列 |

## 拒绝策略

队列满且线程数达到上限时触发拒绝策略。默认是 AbortPolicy，直接抛出异常；也可以改成调用方执行或丢弃最旧任务。

## 常见误区

把 workQueue 设成不传容量的无界队列，会让 maximumPoolSize 永远用不上，任务只会无限堆积，看起来"没报错"其实是在攒雷。

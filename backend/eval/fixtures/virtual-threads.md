# 虚拟线程使用要点

## 与平台线程的区别

虚拟线程由 JVM 调度，多个虚拟线程复用一个载体线程。阻塞时虚拟线程会让出载体，因此可以开到百万级，而平台线程只能开几千个。

## 什么时候有用

虚拟线程只对**阻塞式**任务有收益，比如等待网络或数据库。纯计算任务用它没有好处，反而多了一层调度。

## 注意 ThreadLocal

虚拟线程数量极大，缓存 ThreadLocal 会让内存迅速膨胀，能用局部变量就别用 ThreadLocal。

| 场景 | 平台线程 | 虚拟线程 |
| --- | --- | --- |
| 阻塞等待 | 占住线程 | 让出载体 |
| 纯计算 | 合适 | 无优势 |
| 数量级 | 千级 | 万级以上 |

## 与线程池的关系

虚拟线程不应再套线程池：创建本身很便宜。反过来，把虚拟线程丢进固定大小的线程池会把并发度卡死在池容量上。

# Java 锁与并发原语

## synchronized

synchronized 是可重入的内置锁，编译后靠监视器实现。JDK 1.6 之后引入了偏向锁、轻量级锁到重量级锁的升级路径，所以"没竞争时很便宜"。

## ReentrantLock

ReentrantLock 比 synchronized 多了三件事：可中断获取、超时获取、公平锁选项。代价是必须手写 try/finally 释放，容易漏。

## 读写锁

读多写少的场景用读写锁能提升吞吐：读之间不互斥，读与写互斥。

| 原语 | 可重入 | 可超时 | 适用场景 |
| --- | --- | --- | --- |
| synchronized | 是 | 否 | 简单互斥 |
| ReentrantLock | 是 | 是 | 需要超时或中断 |
| 读写锁 | 是 | 是 | 读多写少 |

## 乐观锁

CAS 属于乐观策略：先比较再写入，失败就重试。它在低冲突时比加锁快，但高冲突时会空转浪费 CPU，还可能遇到 ABA 问题。

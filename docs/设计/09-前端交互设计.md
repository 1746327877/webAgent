# 09 前端交互设计

## 9.1 页面与布局

```
/login  /register
/                     # 主工作台（三栏）
│  ├─ 侧边栏 280px：新建任务 / 智能体列表 / 知识库入口 / 历史会话(搜索·按时间分组·右键删除归档置顶)
│  ├─ 会话区（自适应）：欢迎语+示例问题(空会话) | 消息流 | 输入框
│  └─ 右侧面板（可选抽屉）：引用详情 / 会话信息
/agents               # 智能体列表（卡片：emoji/标签/模型/描述）
/agents/:id           # 智能体编辑器：基本信息 | 提示词(变量高亮) | 参数滑杆 | 工具勾选矩阵 | 知识库绑定 | 版本历史
/kb  /kb/:id          # 知识库列表 / 文档详情（上传区+状态徽章+chunk预览+失败重试）
/admin/*              # dashboard / sessions / traces / tools / models(显存) / alerts（admin 角色）
```

## 9.2 关键交互实现

| 交互 | 方案 |
|---|---|
| **`/` 技能面板** | textarea 值变化时检测**行首或空格后**的 `/` → 浮层命令面板（当前智能体绑定工具 + 全局命令 `/clear` `/model` `/kb`）；↑↓ 选择、Enter 确认、Esc 关闭、继续输入前缀过滤；选中插入 **pill 标签**（chips 输入框），提交时 pill 序列化为结构化 `tool_hints` 随消息发送 |
| **`@` 提及** | 检测行首/空格后 `@` → 智能体弹层（emoji 头像 + 名字 + 一句话描述，可搜索）；插入 `@名字` pill → `mentions[]`；接力回答消息头显示「接力自 @xx」 |
| **引用来源** | `citation` 事件先于 token 到达 → 消息底部先渲染"回答依据"折叠区；正文 `[n]` 渲染为蓝色角标（正则后处理 markdown token）；hover 卡片：文件名/页码/片段/双通道得分；点击 → 右侧抽屉打开原文定位 |
| **思考链折叠** | `thinking` block → 灰色斜体折叠面板；streaming 时自动展开 + "思考中…"呼吸动画；`done` 后折叠，头部「已深度思考 · 用时 3.1s」；全局设置"默认展开思考链" |
| **消息操作** | hover 工具条：复制（取 blocks 原始 markdown，非渲染文本）/ 重新生成 / 编辑重发（仅用户消息：行内编辑 → 确认后截断重发）/ 👍👎（`PATCH /messages/{id}` rating，仪表盘统计反馈率） |
| **工具卡片** | `tool_call/tool_result` block → 紧凑卡片：工具名 + 参数摘要 + 状态点 + 耗时；展开看输入输出 JSON |
| **模型切换提示** | `model_switching` 事件 → 输入框上方进度条"正在切换到 deepseek-r1…（首次约 20s）"；侧边栏智能体项显示"当前驻留"徽标 |
| **长会话性能** | react-virtuoso 虚拟滚动；流式 token 写入 per-message Zustand slice，`rAF` 合帧批量 flush，仅该消息组件订阅重渲染；markdown 块 `memo` + 渲染节流（>50 token/ms 时降级为纯文本追加，流结束统一渲染） |

## 9.3 状态管理划分

| 库 | 管什么 | 理由 |
|---|---|---|
| Zustand | chatStore：流式缓冲、当前会话 blocks、`generating` 状态；uiStore：面板开关、主题 | 高频更新、细粒度订阅 |
| TanStack Query | 智能体/知识库/会话列表/后台数据等一切 CRUD | 缓存、失效重取、乐观更新 |
| SSE | 原生 EventSource 不能 POST → 自封装 `fetch` + `ReadableStream` 解析器（带 AbortController 支持停止） | — |

## 9.4 设计细节

- 深浅色主题（CSS variables + shadcn token）；消息气泡仅用户侧着色，助手消息通栏（类 ChatGPT，提高长文阅读宽度）。
- 代码块：语言标签 + 一键复制 + 横向滚动（shiki 高亮，流式期间用轻量高亮避免抖动）。
- 空状态：新会话显示智能体欢迎语 + 3 个可点击示例问题。
- 错误态：`error` 事件 → 消息内联红色提示 + "重试"按钮（触发 regenerate）。
- 所有列表页支持键盘导航（j/k 或 ↑↓），后台表格支持列排序与筛选器组合。

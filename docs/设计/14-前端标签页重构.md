# 14 · 前端标签页重构（可观测性 / 智能体编辑器 / 过渡动画）

> 状态：设计已定，实施中
> 关联：`09-前端交互设计.md`、`12-扩展能力与MCP.md`、`04-智能体管理模块.md`

## 14.1 背景与目标

当前前端有三处体验问题：

1. **可观测性页面只有一个仪表盘**，调用链（`/admin/sessions/:id`）与"会话记录"入口分散在聊天页的"查看调用链"里，不能在同一处浏览。
2. **智能体编辑器的「扩展能力」纵向堆叠** Skill / MCP / Tool 三块，内容变多就要一直滚动；且 MCP 工具**只能一个个勾选**，8 个工具要点 8 次。
3. **标签页切换生硬**，没有过渡。

目标：统一标签页交互组件、补上过渡动画、给可观测性加子标签页、给批量勾选加"父级全选"。

## 14.2 决策（已确认）

| 事项 | 决策 |
|---|---|
| 可观测性子标签页 | **概览 / 调用链 / 会话记录** |
| 「会话记录」内容 | **会话列表**（标题/智能体/时间），可下钻到该会话调用链 |
| 过渡动画 | **淡入 + 轻微上滑**（约 200ms），尊重 `prefers-reduced-motion` |
| 全选范围 | MCP 每个 server 一个父复选框（全选其下 tool）；Skill、内置 Tool 各加"全选/清空" |

## 14.3 共享标签页组件

新增 `frontend/src/components/ui/tabs.tsx`（手写，不引新依赖）：

- `<Tabs value onChange items ariaLabel />`：`role="tablist"` + `role="tab"` + `aria-selected`；激活项下方一条指示条。
- `<TabsPanel>`：内容容器，进入时应用 `animate-in fade-in-0 slide-in-from-bottom-1 duration-200 motion-reduce:animate-none`（`tw-animate-css` 已在 `index.css` 引入）。
- 面板由调用方按 `value` 条件渲染，因此每次切换都重新挂载并播放进入动画；不做离场动画（保持实现简单、无布局抖动）。

统一改用的位置：`CapabilitiesPage`、`AgentEditorPage`（顶层三标签 + 扩展能力子标签）、新增的 `AdminPage`。

## 14.4 可观测性页面（`/admin`）

新增 `pages/AdminPage.tsx`，两个子标签：

- **概览**：原 `AdminDashboardPage`（指标卡片 + 四张图）原样复用作为内容。
- **会话记录**：顶部**智能体筛选**（全部 / 某个智能体）→ 左侧筛选后的会话列表 → 右侧内嵌 `TraceView`（消息列表 + waterfall + 工具日志 + span 抽屉）。点会话即看该会话调用链，无需切换页面。
  - 列表项展示：标题、智能体、最后活动时间、置顶/归档标记。

> 调整记录：初版有独立的「调用链」标签，按使用反馈**合并进「会话记录」**（筛选 + 主从布局），减少一次跳转。

路由：

- `/admin` → `AdminPage`（懒加载，echarts 仍然按路由分包）。
- `/admin/sessions/:sessionId` → 保留（聊天页"查看调用链"深链），行为不变，内部复用 `TraceView`。

补充（体验修复）：

- 调用链深链页左上角新增 **「←」返回箭头**（`TraceView` 的 `backTo` 参数），单击直接回到该会话的对话 `/sessions/:id`，不必再绕侧边栏；嵌入「会话记录」标签时不显示该箭头。
- 聊天列表滚动：`MessageList` 改为 **等待历史消息加载完再挂载**（避免先渲染顶部再跳到底部的割裂感）；`followOutput` 由 `'smooth'` 改为 `'auto'`（流式高频追加时动画追不上，反倒显得跳）；并开启 `alignToBottom`（内容不足一屏时贴底）。

## 14.5 智能体编辑器

- 顶层标签沿用：**基础信息 / 扩展能力 / 知识库**，改用共享 `Tabs` 并加过渡。
- 「扩展能力」内容抽为 `components/agents/CapabilityBindings.tsx`，内部再用子标签：**Skill / MCP / Tool**（替代纵向堆叠，避免长滚动）。
- 批量勾选：
  - MCP：每个 server 标题前一个父复选框，勾选=全选该 server 全部 tool；部分选中用 `indeterminate`；顶部再加"全选所有 / 清空"。
  - Skill、内置 Tool：各加"全选 / 清空"。
- 语义：父复选框"全选子级"是**勾选即全选**（默认行为），取消则清空该组。

## 14.6 测试

- `tabs.test.tsx`：渲染、切换回调、`aria-selected`、面板带过渡 class。
- `AgentEditorPage` / `CapabilityBindings`：子标签切换；MCP 父复选框全选/取消；部分选中 `indeterminate`。
- `AdminPage`：三个标签渲染；会话记录列表渲染并可跳转；调用链标签渲染 `TraceView`。
- 现有 `CapabilitiesPage` / `AdminDashboardPage` / `AdminTracePage` 测试保持通过（组件复用而非重写）。

## 14.7 已知限制

- 标签页状态用组件本地 state（不写 URL query），刷新后回到默认标签；深链仍由 `/admin/sessions/:id` 提供。
- 只做进入动画，不做离场动画。
- 会话记录列表暂不展示消息数（后端 `GET /api/v1/sessions` 未返回该字段，避免为此改接口）。
